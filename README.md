## Who is the user?
The user is a beginner or student(me) who wants to learn and improve their Python skills.

## What problem are you solving?
Learning Python can be difficult because exercises are not always adapted to the user's level. Our project provides personalized exercises based on the user's level and progress.

## What can the LLM improve?

Explanation: Explain Python concepts in a simple way based on the user's level.

Examples: Generate examples when the userr doesn't understand.

Exercises: Create new exercises adapted to the user.

Hints: Give hints when the user is stuck without giving the answer directly.

Difficulty adaptation: Make exercises easier or harder depending on the user's results.
